Agent Architecture · Module 0 · Topic 0.4

Where This Came From

Date-stamp any agent pattern on sight, so a 2023 fossil in a 2026 pitch deck never gets past you.

Landscape topic: history, verified against the field-notes snapshot rather than re-searched · builds on 0.1, 0.2, 0.3 · ~7 min read · closes Module 0

1Why this exists

Between 2022 and 2024 the field ran a massive natural experiment: what do you have to wrap around a language model to make it do things instead of just say things? Four generations of answers shipped, got hundreds of thousands of GitHub stars, raised money, and then mostly died. You were promised one sitting on this, and one sitting is what it deserves. But you cannot skip it, for two reasons.

First, the vocabulary survived the wreckage. ReAct, chain-of-thought, AutoGPT, agent crews: these names show up in every paper, every framework's docs, and every founder pitch you will ever evaluate. Second, and more useful: the failures were not random. They all failed the same way, and that failure mode is alive and well in 2026 products. This lesson gives you a dating technique. When someone shows you an agent architecture, you should be able to say which year it is from, and therefore what will kill it.

2The mental model

Carry this out of the room Agent history is one repeated lesson: scaffolding that substitutes for model capability gets eaten by the next model release, while scaffolding that contains consequences survives every one of them.

Every era below built scaffolding, in the 0.1 sense: harness around the model. The question that sorted survivors from fossils was what the scaffolding was for. Hand-written reasoning templates, self-criticism steps, task-decomposition planners, role-play org charts: all of these were prosthetics for judgment the models did not yet have, and each one became dead weight the moment models grew the ability natively. Verifiers, sandboxes, human gates, context discipline: these manage what happens when the model acts, and no model release makes consequences go away. You already met this split at the end of 0.3 as scaffolding that contains consequences versus scaffolding that substitutes for judgment. This lesson is where that distinction came from: it is the autopsy finding from an entire era.

3The landscape

A landscape of: how do you get a text predictor to act on the world?
What varies: where each era located the agency: in the prompt, in the prompt plus a loop, in an unbounded loop, or in a framework's org chart. Four answers, oldest to newest. All four wear the Legacy badge; this is a museum wing, and the plaques explain why each exhibit lost.
Reading the diagrams: gray is shared structure; teal is what this era added; the amber dot marks where it broke.

Chain-of-thought prompting Legacy

January 2022, Wei et al. at Google. The discovery that asking a model to write out intermediate reasoning steps before answering dramatically improves multi-step performance. Agency lives entirely in the prompt; the model still only talks. This is the ancestor of everything: the first proof that you could buy capability with tokens instead of training.

Wins: unlocked multi-step reasoning for free; made model thinking legible for the first time. Costs: thoughts touch nothing; hand-curated exemplars were brittle; the whole technique was a prosthetic for reasoning the models later grew natively, which is exactly why reasoning models absorbed it and retired the prompt trick.

Done right: still the right call inside a fixed workflow step (0.2's territory) when you need auditable intermediate work in a specific format from a cheap non-reasoning model, such as a triage step that must show its scoring rubric.

ReAct Legacy

October 2022, Yao et al. at Princeton and Google Brain. Interleave Thought, Action, and Observation in one prompt: the model reasons, emits a text action like Search[query], the harness parses it, runs the tool, pastes the result back, and the model continues. Recall 0.1: "An agent is a model running in a loop with tools. Everything in the system that is not the model is the harness, and the harness is what you get to design." ReAct is where that loop was born. The paper's prompting pattern is dead; the loop it named is the substrate of every agent you use.

Wins: grounded reasoning in real observations; halved hallucination on knowledge tasks; gave the field its loop. Costs: actions were regex-parsed free text, so the harness broke on every formatting wobble. In 0.3's terms, "a tool is two things at once: a contract with a deterministic system, and a prompt aimed at a non-deterministic one," and ReAct-era tools had no contract half at all. Native tool calling (structured, schema-validated) killed the pattern in 2023.

Done right: as a prompting technique, on a small open model with no native tool calling where you need transparent traces on a budget. As an architecture, you use it every day: it is 0.1's loop wearing its maiden name.

Autonomous goal loops Legacy

Spring 2023: AutoGPT and BabyAGI. Hand the model a goal, let it decompose the goal into a task queue, execute, generate new tasks, and loop until it declares itself done. No human in the loop, no verifier anywhere. AutoGPT became one of the fastest-starred repositories in GitHub history on the strength of demos, and almost nothing built on it shipped.

Wins: proved enormous demand for delegation; generated the field's best catalog of failure modes. Costs: recall 0.2: "The question is never 'is this an agent.' It is 'how much control flow did I delegate to the model, and can I verify what it does with it?'" AutoGPT was maximum delegation with zero verification: the model graded its own homework, so loops spiraled, costs compounded, and context overflowed until the run drowned in its own transcript.

Done right: almost never as shipped, but the ambition was correct and returns in today's outer-loop coding agents, where the shape is only safe because a mechanical verifier (the test suite, the compiler) decides "done" instead of the model's self-assessment.

Role-play framework crews Legacy

2023 to 2024: the framework era. LangChain-style agent abstractions first, then multi-agent crews (CrewAI, early AutoGen) that decomposed work by job title: a PM agent writes the spec, an engineer agent implements, a QA agent reviews. Agency lives in the framework's org chart. It felt intuitive because it copied how humans organize, and that was precisely the mistake.

Wins: onboarded a generation of builders; normalized the idea of agent systems; some graph-shaped descendants survive where auditability matters. Costs: the abstractions leaked, so debugging meant excavating five wrapper layers to find the one prompt that mattered; and job-title splits fragment one task's context across agents that each hold a different partial picture, making conflicting implicit decisions. Anthropic's 2026 guidance names role-play crews a legacy anti-pattern: decompose along context boundaries, never job titles. That fight gets its full treatment in 4.2.

Done right: the framework instinct, minus the role-play, survives as deterministic graph shells around agentic nodes in compliance-heavy enterprises where every transition must be auditable; that redemption arc is 4.5.

5Seen in the wild

Put AutoGPT itself on the dissection table, using 0.1's lens: loop, tools, context.

The loop. AutoGPT ran a genuine loop: gather (read the task queue), act (execute a command), repeat. But hold it against 0.1's four beats and one is missing: there is no verify beat at all. In its place sat a self-criticism step: the model prompted to critique its own plan before acting. That is verification-shaped scaffolding with no grounding, the model grading its own homework, and its descendants die on the same sword in 5.5. The beat structure was right; one beat was faked.

The tools. A flat command list: browse, write file, spawn agent, execute code. Free-text invocations, string-parsed, un-sandboxed code execution on the user's own machine. Every 0.3 sin in one place: no contract half, no containment, and this is why 7.2's containment stack exists.

The context. The most instructive failure. AutoGPT appended every thought, action, and result to one ever-growing transcript until it overflowed the tiny windows of 2023. The community's fix was to bolt on a vector database and cosine-retrieve "relevant memories" back into context. That bolt-on became the default memory architecture of an entire era, and its rise and demotion is a story 2.8 tells in full.

Notice what this dissection buys you: AutoGPT was not wrong about the destination. Long-horizon autonomous delegation is exactly what 2026's best agents deliver. It was wrong about what to build first. It built ambition scaffolding on top of missing judgment; the field spent the next three years building verification, containment, and context discipline underneath the same ambition.

The misconception "AutoGPT was just early. The models were too weak in 2023, and today's models vindicate the design." Half right, and the wrong half gets remembered. Drop a 2026 frontier model into AutoGPT's harness and you do not get a working agent; you get a more expensive failure, because the harness still has no verifier, no context discipline, and no gate on consequences. The models were weak AND the architecture was wrong, and only one of those problems was fixed by waiting. The clean test for any fossil: if the idea lived at the capability layer (chain-of-thought), model progress absorbed it; if it lived at the consequence layer (verification, containment), model progress made it more necessary, not less.

6Check yourself

A 2026 startup pitches you: "A crew of AI employees: our AI PM writes the spec, the AI engineer implements it, the AI QA agent tests it. Fully autonomous, no humans needed." Date-stamp the architecture and name the one question you would ask first.

Two fossils stacked: a role-play crew (2023-24, job-title decomposition that fragments one task's context) wrapped in an autonomous goal loop (spring 2023, "fully autonomous" with no mention of verification). The first question: what, outside your models, decides that the work is done and correct? If the answer is "the QA agent," that is the model grading its own homework with extra steps. A defensible version would decompose along context boundaries and let a test suite or a human gate own "done."

You find a prompt in your own product that says "First, think step by step. List your reasoning as numbered points, then give your answer." It runs on a frontier reasoning model. Keep or cut?

Cut, with one exception. On a reasoning model this is substitution scaffolding aimed at a capability the model already has natively; at best it wastes tokens, at worst it fights the model's own trained reasoning behavior. The exception is when you need the intermediate work in a specific auditable format for a downstream consumer (a log, a reviewer, a parser): then you are buying a format contract, not reasoning, and the instruction should say so explicitly.

ReAct's prompting pattern died within a year, yet its loop became the substrate of every modern agent. Why did one half survive and not the other?

The mental model, applied. The pattern half (free-text actions, regex parsing, hand-built exemplars) substituted for a capability models lacked: structured tool invocation. Native tool calling arrived and ate it. The loop half (act, observe the real result, reason again) is consequence architecture: it grounds the model in what actually happened in the world, and no model release makes the world's feedback unnecessary. Substitution died; containment survived. That split is the whole lesson.

Done when Module 0's bar is sketching any agent product as loop + tools + context and saying which parts are workflow and which are agent; 0.1 through 0.3 gave you that. This topic contributes the historical layer of the same skill: when you see ReAct, chain-of-thought, AutoGPT, or an agent crew invoked in a paper, a framework, or a pitch, you can date the pattern, say why it lost, and spot its failure mode recurring in a modern design. That closes the module.
